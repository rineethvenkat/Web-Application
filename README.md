# Foodie Web Application

A simple, polished food ordering web app with:
- a welcoming home page
- a menu for browsing dishes
- a working cart experience
- user registration and login
- a contact page for feedback

## Run locally
Open the project folder in a browser, or start a local server from the project directory:

```bash
python -m http.server 8000
```

Then visit http://127.0.0.1:8000/index.html
